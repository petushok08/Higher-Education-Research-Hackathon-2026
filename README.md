# Совмещение учёбы и работы: польза или помеха?

Проект для **Хакатона исследователей высшего образования – 2026** (НИУ ВШЭ), задача «Лонгитюд образовательного поведения студентов».

## О проекте

Многие студенты начинают работать ещё во время учёбы. Работа может давать опыт, деньги и понимание профессии, но может и отнимать время у учёбы, сна и отдыха.

**Цель:** по данным лонгитюдного исследования выяснить, в каких аспектах совмещение учёбы и работы приносит студентам пользу, а в каких создаёт дополнительные трудности. Для этого я смотрю, как с успеваемостью, образовательным опытом и здоровьем студентов связаны:
- сам факт работы;
- интенсивность занятости (полный / неполный день, приработки, часы в неделю);
- тип занятости (сфера, соответствие специальности, мотив).

## Данные

Лонгитюдное исследование «Модели образовательного поведения студентов в их связи с показателями успешности» (Институт образования НИУ ВШЭ): 9 селективных российских вузов, 3-я волна (2024/25, 3 курс) и 4-я волна (2025/26, те же студенты на 4 курсе).

**Данных в репозитории нет.** Массив с ответами студентов выдан организаторами хакатона, и по правилам его нельзя публиковать. Чтобы запустить ноутбук, положите файл `Лонгитюд_массив.sav` в папку `data/` в корне проекта.

## Как запустить

Python 3.13, библиотеки: `pandas<3`, `numpy`, `pyreadstat`, `scipy`, `statsmodels`, `scikit-learn`, `matplotlib`, `seaborn`, `dython`, `notebook`.

```bash
pip install "pandas<3" numpy pyreadstat scipy statsmodels scikit-learn matplotlib seaborn dython notebook
jupyter notebook students_work_study_analysis.ipynb
```

Ноутбук запускается из корня проекта: путь к данным — `data/Лонгитюд_массив.sav`.
